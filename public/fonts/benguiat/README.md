# ITC Benguiat Std

Dizajn koristi **ITC Benguiat Std** za naslove.

Dodaj sledeće fajlove u ovaj folder (iz tvoje font licence ili exporta iz Figme):

- `BenguiatStd-Book.woff2` (font-weight: 400)
- `BenguiatStd-Bold.woff2` (font-weight: 700)

Dok fajlovi nisu prisutni, browser koristi fallback (Georgia, serif).
